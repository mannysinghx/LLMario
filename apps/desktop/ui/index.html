Models

Have your own model? Drag a .gguf file or an MLX model folder onto this window. It is added in place, never copied, and removing it never deletes your files.

Engines run the models. Install llama.cpp (brew install llama.cpp) for GGUF models, and MLX-LM (pip install mlx-lm) for MLX models on Apple Silicon. Install llama.cpp for GGUF models: run winget install ggml.llamacpp in a terminal, then restart LLMario. Install llama.cpp for GGUF models: build it from github.com/ggml-org/llama.cpp or use your distribution's package. A model marked "needs a newer engine" uses an architecture your installed version cannot load yet.
